# BOOKLOOM BORDER RADIUS SYSTEM

Version: 1.0

Status: Approved

Priority: Critical

---

# PURPOSE

Border radius creates softness, approachability, and visual consistency.

Every curve in BookLoom should feel intentional.

Rounded corners are part of the brand language—not decoration.

---

# DESIGN PHILOSOPHY

BookLoom is inspired by

Luxury stationery

↓

Premium notebooks

↓

Modern architecture

↓

Editorial layouts

↓

Minimal software

Corners should feel refined.

Never overly rounded.

Never aggressively sharp.

---

# CORE PRINCIPLE

Every component uses predefined radius tokens.

Never invent new radius values.

# RESPONSIVE RULES

Desktop

100%

100%

Mobile

---

# SHAPE LANGUAGE

Large surfaces

Larger radius.

Small interactive controls

Smaller radius.

Visual hierarchy should be reinforced through shape.

---

# DO NOT USE

0px on cards

Sharp buttons

Random radius values

Mixed radii within the same component

Excessive pill shapes

Overly rounded "bubble" UI

---

# ACCESSIBILITY

Rounded corners must never reduce hit areas.

Maintain minimum touch target of

44 × 44px.
