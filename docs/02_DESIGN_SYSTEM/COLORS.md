# BOOKLOOM COLOR SYSTEM

Version: 1.0

Status: Approved

Priority: Critical

---

# PURPOSE

This document defines every color used in BookLoom.

No page may introduce new colors.

No component may invent colors.

No gradients may use undocumented colors.

Every color exists as a Design Token.

---

# DESIGN PHILOSOPHY

BookLoom is inspired by

Luxury Publishing

↓

Editorial Design

↓

Museum Catalogues

↓

Premium Stationery

↓

Minimal Architecture

The interface should feel

Warm

Elegant

Calm

Sophisticated

Timeless

Never cold.

Never overly saturated.

Never neon.

Never gaming inspired.

Never cyberpunk.
