# BOOKLOOM TYPOGRAPHY SYSTEM

Version: 1.0

Status: Approved

Priority: Critical

---

# PURPOSE

Typography is the primary visual language of BookLoom.

Users should remember the reading experience more than the interface.

Typography creates hierarchy, trust, elegance, and rhythm.

When typography is correct, the UI feels effortless.

---

# DESIGN PHILOSOPHY

Typography is not decoration.

Typography is architecture.

Whitespace and typography work together.

Large type creates confidence.

Small type creates precision.

Every font size has a purpose.

# TYPOGRAPHY RULES

Never mix more than

Two font families.

Never use decorative fonts.

Never stretch text.

Never compress text.

Never use fake bold.

Never use fake italics.

Never center long paragraphs.

Never justify body copy.

Never reduce readability for style.

---

# FINAL RULE

Typography is the heart of BookLoom.

If a screen works without illustrations but still feels beautiful because of its typography,

the typography is correct.
