# BookLoom Code Review Policy

Version: 1.0

Status: Approved

---

# Purpose

Ensure every code change improves the platform while maintaining quality, security, and maintainability.

---

# Goals

Maintain consistency

Share knowledge

Prevent defects

Improve architecture

Protect security

---

# Every Pull Request Must

Compile successfully

Pass CI

Pass tests

Pass linting

Include documentation updates (if applicable)

Include migration notes (if applicable)

---

# Reviewer Checklist

Correctness

Readability

Architecture

Performance

Accessibility

Security

Testing

Documentation

Backward compatibility

---

# Approval Requirements

Minor Changes

1 approval

Major Features

2 approvals

Architecture Changes

Architecture owner approval

Security Changes

Security review required

---

# Review Principles

Review the code—not the developer.

Provide actionable feedback.

Prefer explanation over opinion.

Suggest improvements.

Respect established conventions.

---

# Merge Rules

No failing CI

No unresolved review comments

No merge conflicts

Required approvals complete

---

# Final Rule

Every review should leave the codebase better than it was before.
