# Dependency Management Policy

Version: 1.0

---

# Purpose

Control third-party dependencies.

---

# Rules

Every dependency must

Have active maintenance

Have compatible licensing

Pass security review

Provide long-term stability

Be documented

---

# Updates

Critical security updates

Immediately

Minor updates

Monthly

Major updates

Architecture review required

---

# Removal

Unused dependencies

Deprecated packages

Abandoned libraries

Must be removed promptly.

---

# Final Rule

Every dependency introduces long-term maintenance responsibility.
