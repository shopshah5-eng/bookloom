# PURPOSE

Publishing transforms manuscripts into professionally distributed books.

Publishing should feel exciting—not stressful.

Users should always know

• what is happening

• what will be published

• where it will be published

• what needs attention

---

# DESIGN PHILOSOPHY

Publishing is a guided workflow.

Never expose users to dozens of confusing settings.

Progressive disclosure reveals advanced options only when necessary.
