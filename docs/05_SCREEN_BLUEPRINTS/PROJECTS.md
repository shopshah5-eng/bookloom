# BOOKLOOM PROJECTS

Version: 1.0

Status: Approved

Priority: CRITICAL

---

# PURPOSE

The Projects page is the user's digital library.

It is where every manuscript, book, article, screenplay, course, notebook, and publication lives.

Unlike a traditional file manager, BookLoom organizes creative work—not files.

Users should feel like they are browsing their personal publishing studio.

---

# PRIMARY GOALS

Enable users to

• View every project

• Continue writing quickly

• Organize work

• Search instantly

• Filter intelligently

• Create new projects

• Archive completed books

• Collaborate
