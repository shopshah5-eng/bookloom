# BOOKLOOM DASHBOARD

Version: 1.0

Status: Approved

Priority: CRITICAL

---

# PURPOSE

The Dashboard is the user's publishing studio.

It is not an analytics dashboard.

It is not an admin panel.

It is the place where every writing journey begins.

Every element should help the user answer one question:

"What should I work on next?"

---

# PRIMARY GOALS

The dashboard should allow users to

• Continue writing immediately

• Find projects quickly

• Create a new project

• Access AI tools

• View recent activity

• Monitor writing progress

• Discover templates

• Reach every feature within two clicks
