# Writing Canvas Specifications

- Editor Architecture: TipTap / ProseMirror block document model capable of supporting manuscripts exceeding 500,000 words.
- Block System: Paragraph, Heading 1-6, Blockquote, Callout, Code Block, Table, Image, Math Equation, Checklist, Page Break.
- Inline Formatting: Bold, Italic, Underline, Strikethrough, Highlight, Code, Subscript, Superscript, Hyperlinks, Comments.
- Review & Track Changes: Isolated suggestion layer, inline comment threads, reviewer attribution, accept/reject diffs.
- Autosave & Recovery: 2-second debounced continuous autosave, offline local cache, 5-minute snapshot history.
- Writing Modes: Normal, Focus (Zen), Typewriter, Print Layout Preview.
