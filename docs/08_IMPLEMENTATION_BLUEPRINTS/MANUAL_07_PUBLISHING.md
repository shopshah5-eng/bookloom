# Publishing Pipeline Specifications

- Intermediate Publishing Model: Format-agnostic manuscript representation isolating content from print and digital presentation rules.
- Export Formats: PDF (Print & Screen), EPUB 3.0, DOCX (Microsoft Word), HTML5, Markdown (GFM), and Plain Text.
- Print Layout Engine: Custom trim sizes (6x9", 5.5x8.5", A5), page bleed, crop marks, gutter margins, running headers/footers, drop caps, widow/orphan control.
- Metadata & Identifiers: ISBN-10, ISBN-13, DOI, Dublin Core, Schema.org, Open Graph, and EPUB package metadata.
- Preflight Validation: Automated pre-export quality checks for missing images, broken links, missing metadata, and WCAG accessibility conformance.
