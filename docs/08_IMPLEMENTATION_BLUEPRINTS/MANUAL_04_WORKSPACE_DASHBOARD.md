## Workspace, Projects & Dashboard Platform

Version: 1.0
Status: Official
Priority: Critical

---

# Architecture Specifications

- Application Shell: Authenticated layout with collapsible sidebar, top navigation header, command palette integration (`Cmd+K`), notification drawer, and content viewports.
- Workspace System: Multi-tenant workspace switcher, member roles (Owner, Admin, Editor, Contributor, Viewer), workspace settings, and branding.
- Project & Folder Hierarchy: Workspace -> Projects -> Folders -> Books -> Chapters -> Documents.
- Dashboard Platform: Customizable dashboard widgets displaying recent documents, writing stats (word count, reading time), pinned favorites, and recent activity.
- Book Lifecycle Management: Grid/list book views, cover previews, word count tracking, status badges (Draft, Review, Editing, Published), and soft deletion.
