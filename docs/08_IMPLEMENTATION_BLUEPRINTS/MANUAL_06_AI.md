# AI System Specifications

- Provider Abstraction: Modular integration for OpenAI, Anthropic, Google Gemini, Ollama, OpenRouter, and custom local endpoints.
- Prompt Engine: Versioned prompt templates, token budgeting, dynamic variable resolution, context assembly, and safety checks.
- Agent & Tool Execution: Autonomous agents for research, editing, chapter outline generation, and publishing copy creation.
- RAG & Vector Memory: Hybrid keyword + semantic search over workspace manuscripts, research notes, and character bibles.
- Multi-Model Router: Cost-and-latency-aware model router prioritizing small fast models for grammar/style checks and large reasoning models for long-form book generation.
