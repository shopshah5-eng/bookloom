# Design Philosophy

BookLoom combines the visual elegance of Linear, Notion, Raycast, and Apple with a high-contrast dark-mode default, fluid typography, and bento grid layouts.

---

# Token Architecture

- Colors: Semantic background, surface, text, border, status (success, warning, danger, info), and brand primary/secondary tokens.
- Typography: Inter Tight (Display/Headings), Inter (Body text), JetBrains Mono (Code/Equations).
- Spacing: 8pt grid system (0, 2, 4, 6, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128).
- Radius: scale from None to 3XL and Full.
- Elevation Shadows: Soft glassmorphic backdrop blurs and subtle dark-mode glow rings.
- Motion: Purposeful micro-interactions with reduced-motion support.

---

# UI Primitive Catalog

- Typography: Headings, Body, Code, Subtitles, Captions.
- Layout: Stack, Grid, Flex, Container, Section, Divider, AspectRatio.
- Interactive: Button, Input, Textarea, Select, Checkbox, Radio, Switch, Slider.
- Feedback: Toast, Spinner, Progress, Skeleton, Alert, EmptyState.
- Overlays: Dialog, Drawer, Popover, DropdownMenu, CommandPalette, Tooltip.
- AI Primitives: AIChatBubble, AIThinkingIndicator, AISuggestionCard, ModelSelector.
