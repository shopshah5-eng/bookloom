# ADR-002 — Editor Technology

Status

Accepted

---

# Context

The editor is the most important feature of BookLoom.

Requirements

Rich Text

Collaboration

Offline Support

Markdown

Version History

AI Integration

Publishing

Scalability

---

# Decision

Use

TipTap

built on

ProseMirror.

---

# Why TipTap

Headless

Extensible

Excellent plugin ecosystem

Battle-tested

Excellent collaboration support

Strong Markdown ecosystem

Works well with AI

Custom nodes

Custom marks

Future-proof architecture

---

# Alternatives

Lexical

Excellent performance

Still evolving ecosystem

Not selected.

---

Slate

Flexible

Large maintenance burden

Rejected.

---

Quill

Simple

Not extensible enough

Rejected.

---

CKEditor

Powerful

Heavy

Commercial focus

Rejected.

---

# Consequences

Positive

Production-ready

Highly customizable

Excellent community

Enterprise adoption

Negative

Steeper learning curve

Complex extension API

---

# Future Review

Revisit only if

TipTap becomes unsupported

Or a significantly superior editor ecosystem emerges.

Accepted
