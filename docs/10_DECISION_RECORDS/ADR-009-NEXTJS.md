# ADR-009 — Frontend Framework

Status: Accepted

---

## Decision

Use Next.js (App Router) as the primary frontend framework.

## Why

- React ecosystem
- Server Components
- Streaming
- SSR
- SSG
- Route Handlers
- Excellent TypeScript support
- Edge compatibility

## Alternatives

Remix — Excellent routing, smaller ecosystem.

Nuxt — Vue ecosystem.

SvelteKit — Smaller ecosystem.

Rejected.

## Decision

Accepted.
