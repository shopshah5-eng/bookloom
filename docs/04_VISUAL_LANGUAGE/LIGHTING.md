# BOOKLOOM LIGHTING SYSTEM

Version: 1.0

Status: Approved

Priority: CRITICAL

---

# PURPOSE

Lighting creates depth.

Lighting creates focus.

Lighting creates atmosphere.

Lighting never becomes decoration.

Users should feel the interface is naturally illuminated rather than artificially lit.

---

# DESIGN PHILOSOPHY

BookLoom uses light the way an architectural space uses natural daylight.

Soft.

Directional.

Comfortable.

Invisible.

The interface should never appear to glow.

Instead, it should feel illuminated.

---

# DESIGN INSPIRATION

Natural daylight entering a quiet library

Premium stationery photographed near a window

Museum galleries

Apple product photography

Luxury architecture

Editorial photography

Fine paper under soft daylight

---

# LIGHT SOURCES

BookLoom recognizes only four light sources.

Natural Ambient Light

↓

Directional Highlight

↓

Surface Reflection

↓

Focus Lighting

Anything outside these categories should be avoided.

---

# AMBIENT LIGHT

Purpose

Defines overall atmosphere.

Characteristics

Very soft.

Evenly distributed.

Almost impossible to notice directly.

Should never create obvious gradients.

---

# DIRECTIONAL LIGHT

Purpose

Adds depth to hero areas.

Allowed

Landing page

Authentication

Marketing banners

Book showcase

Not Allowed

Editor

Dashboard

Forms

Tables

Settings

AI Workspace

---

# SURFACE REFLECTION

Purpose

Separate elevated surfaces.

Characteristics

Extremely subtle.

Appears only on elevated materials.

Never glossy.

Never mirror-like.

---

# FOCUS LIGHT

Purpose

Draw attention to primary actions.

Examples

Focused input

Primary CTA

Selected book

Current document

Active sidebar item

Should never resemble a neon glow.

---

# LIGHT INTENSITY

Very Low

Backgrounds

Low

Cards

Medium

Dialogs

High

Focused Components

Very High

Never used.

---

# LIGHT TEMPERATURE

Warm Neutral

Preferred

Supports long reading sessions.

Avoid cold blue lighting.

Avoid yellow saturation.

---

# LIGHT DIRECTION

Default

Top Left

Maintain consistency across all surfaces.

Do not randomly change perceived light direction.

---

# RADIAL LIGHT

Purpose

Create gentle atmosphere.

Allowed

Landing Hero

Authentication

Premium marketing sections

Feature showcases

Book covers

Forbidden

Editor

Dashboard

Sidebar

Tables

Analytics

Settings

AI Chat

---

# EDGE HIGHLIGHTS

Allowed

Dialogs

Floating panels

Command palette

Hover cards

Very subtle.

Should feel like soft daylight catching an edge.

---

# SHADOW RELATIONSHIP

Lighting and shadows work together.

More light

↓

Softer shadow

Less light

↓

Slightly stronger shadow

Never combine bright highlights with harsh shadows.

---

# GLASS LIGHTING

Glass surfaces may receive

Soft ambient reflection

Very faint edge highlight

Never glowing outlines.

Never colorful reflections.

---

# BUTTON LIGHTING

Primary Button

Subtle highlight

Secondary Button

Flat

Ghost Button

No highlight

Destructive Button

No decorative lighting

---

# CARD LIGHTING

Cards should appear gently lifted.

Never floating dramatically.

Hover

Increase brightness slightly

Increase elevation slightly

Avoid exaggerated lift.

---

# INPUT LIGHTING

Focused Input

Soft highlight

Clear focus ring

Readable border

Unfocused Input

Flat appearance

No glow

---

# MODAL LIGHTING

Dialogs may receive

Soft ambient highlight

Subtle edge reflection

Large diffuse shadow

No spotlight effect.

---

# COMMAND PALETTE

Highest quality lighting.

Feels premium.

Not futuristic.

Should resemble a carefully crafted floating paper panel.

---

# EDITOR

No lighting effects.

Reading takes priority.

Lighting should effectively disappear.

---

# DARK MODE

Dark mode uses reflected light rather than emitted light.

Surfaces become distinguishable through

Slight brightness differences

Soft edge highlights

Subtle elevation

Never use glowing borders.

Never use blue lighting.

Never simulate RGB effects.

---

# ACCESSIBILITY

Lighting must never

Reduce readability

Hide focus states

Decrease contrast

Communicate meaning

---

# PERFORMANCE

Lighting should use

CSS gradients

Opacity

Layered shadows

Minimal blur

Avoid

Heavy filters

Animated lighting

Dynamic reflections

Large GPU-intensive effects

---

# CONSISTENCY

All lighting follows one imaginary light source.

Users should never consciously notice the lighting system.

They should simply feel the interface is calm, premium, and cohesive.

---

# REVIEW CHECKLIST

✓ Natural appearance

✓ Supports hierarchy

✓ Consistent light direction

✓ No unnecessary glow

✓ Accessible

✓ Performance-friendly

✓ Matches editorial aesthetic

---

# FINAL RULE

Lighting should feel like morning sunlight in a quiet publishing studio.

If users describe the interface as "glowing," the lighting is too strong.

If they describe it as "comfortable," it is working exactly as intended.
