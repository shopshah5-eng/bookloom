# BOOKLOOM GRADIENT SYSTEM

Version: 1.0

Status: Approved

Priority: CRITICAL

---

# PURPOSE

Gradients add atmosphere.

They create visual depth.

They highlight moments of importance.

Gradients are never decoration for decoration's sake.

If removing a gradient does not reduce clarity or emotion,
the gradient should not exist.

---

# DESIGN PHILOSOPHY

BookLoom gradients should feel like

Morning sunlight

Premium paper

Soft studio lighting

Luxury publishing

Natural shadows

They should never feel digital.

---

# CORE PRINCIPLES

Large gradients.

Soft transitions.

Low saturation.

Low contrast.

Minimal usage.

One gradient should influence an entire section rather than multiple competing gradients.

---

# WHERE GRADIENTS ARE ALLOWED

✓ Landing Hero

✓ Marketing Sections

✓ Authentication Background

✓ Premium Upgrade Banner

✓ Empty State Illustration Background

✓ Featured Book Showcase

✓ Success Screens

✓ Premium Onboarding

---

# WHERE GRADIENTS ARE NOT ALLOWED

Sidebar

Tables

Forms

Analytics

Settings

Billing

Modals

Dropdowns

Notification Center

Writing Canvas

---

# PRIMARY BRAND GRADIENT

Purpose

Marketing hero.

Feeling

Warm.

Premium.

Editorial.

Direction

Top Left

↓

Bottom Right

Intensity

Very Low

Opacity

Less than 12%

Never use fully saturated colors.

---

# GOLD ACCENT GRADIENT

Purpose

Premium features.

Awards.

Enterprise.

Featured Templates.

Feeling

Elegant.

Metallic.

Refined.

Never use shiny gold.

Never simulate chrome.

---

# LIGHT GRADIENT

Purpose

Background atmosphere.

Characteristics

Almost invisible.

Only detectable when viewed carefully.

Used to soften flat layouts.

---

# DARK MODE GRADIENT

Purpose

Prevent large dark surfaces from appearing flat.

Characteristics

Very subtle charcoal transitions.

No visible color shift.

No blue glow.

No purple glow.

---

# HERO GRADIENT

Largest gradient in the product.

Used only once per page.

Should occupy the entire hero section.

Never stack multiple hero gradients.

---

# CARD GRADIENTS

Not supported.

Cards remain flat.

Exceptions require design approval.

---

# BUTTON GRADIENTS

Primary buttons are solid.

Gradient buttons are prohibited.

Exceptions

Limited marketing campaigns only.

---

# TEXT GRADIENTS

Generally prohibited.

Allowed only for

Large marketing headlines.

Never inside the application UI.

Never on body text.

Never on buttons.

---

# ICON GRADIENTS

Not supported.

Icons use solid colors only.

---

# BORDER GRADIENTS

Not supported.

Borders remain solid.

---

# GLOW GRADIENTS

Not supported.

Glow is not part of BookLoom's visual language.

---

# MESH GRADIENTS

Allowed only

Landing page hero.

Marketing banners.

Never inside product workflows.

---

# RADIAL GRADIENTS

Allowed

Authentication

Landing Hero

Feature Highlights

Premium Upgrade Screens

Not allowed

Dashboard

Editor

Forms

Analytics

---

# LINEAR GRADIENTS

Preferred over mesh gradients.

Simple.

Predictable.

Elegant.

---

# ANGLES

Approved

0°

45°

90°

180°

Avoid unusual angles.

---

# COLOR STOPS

Two stops preferred.

Three stops maximum.

Never create rainbow gradients.

---

# SATURATION

Muted.

Editorial.

Natural.

Never use vibrant colors.

---

# OPACITY

Most gradients should remain between

4%

↓

12%

Maximum

18%

Anything stronger requires explicit approval.

---

# ANIMATION

Gradients should remain static.

Animated gradients are prohibited.

No shifting colors.

No moving light.

No breathing backgrounds.

---

# ACCESSIBILITY

Gradients must never

Reduce readability

Reduce contrast

Hide interface elements

Compete with typography

---

# PERFORMANCE

Prefer CSS gradients.

Avoid image-based gradients.

Avoid SVG meshes unless necessary.

Never animate large gradients.

---

# DESIGN TOKENS

Gradient tokens should define

Purpose

Direction

Stops

Opacity

Theme variants

Never hardcode gradient values inside components.

---

# REVIEW CHECKLIST

✓ Used only where approved

✓ Supports hierarchy

✓ Low saturation

✓ Large scale

✓ Accessible

✓ Performance-friendly

✓ Matches editorial identity

---

# FINAL RULE

A BookLoom gradient should feel like natural light passing over fine paper.

If the user immediately notices the gradient,
it is too strong.
