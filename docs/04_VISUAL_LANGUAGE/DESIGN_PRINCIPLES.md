# BOOKLOOM VISUAL LANGUAGE

Version: 1.0

Status: Approved

Priority: CRITICAL

---

# PURPOSE

This document defines the visual identity of BookLoom.

It explains how BookLoom should feel—not just how it should look.

Every screen, component, animation, illustration, and interaction must reinforce this identity.

If a design decision conflicts with this document, this document takes precedence.

---

# BRAND PERSONALITY

BookLoom is

Elegant

Editorial

Minimal

Calm

Intelligent

Premium

Confident

Creative

BookLoom is never

Corporate

Playful

Gamified

Neon

Cyberpunk

Developer-centric

Flashy

Noisy

---

# EMOTIONAL GOAL

Users should feel

"I've entered a premium publishing studio."

Not

"I'm using another AI SaaS."

---

# DESIGN INSPIRATION

Primary Inspirations

Luxury book publishers

Editorial magazines

Apple Human Interface

Notion (clarity only)

Linear (precision only)

Kindle Reader

Premium stationery

Museum exhibitions

Modern architecture

Never imitate.

Only learn principles.

---

# VISUAL HIERARCHY

Content

↓

Typography

↓

Whitespace

↓

Imagery

↓

Color

↓

Motion

Decoration should always be the last priority.

---

# FIRST IMPRESSION

Within three seconds users should think

"This is beautifully crafted."

Within ten seconds

"This feels trustworthy."

Within one minute

"I want to write here."

---

# WHITESPACE

Whitespace is a feature.

Not empty space.

Every screen should breathe.

Never fill unused space with decoration.

---

# TYPOGRAPHY FIRST

Typography is the hero.

Everything else supports reading.

Buttons never dominate headlines.

Cards never overpower text.

Icons never compete with typography.

---

# CONTENT FIRST

Every layout begins with content.

Decoration is added only when it improves clarity.

---

# VISUAL RHYTHM

Large spacing

↓

Medium spacing

↓

Small spacing

↓

Interactive controls

↓

Fine details

Maintain consistent vertical rhythm.

---

# SIMPLICITY

One focal point per screen.

One primary action per section.

One visual story at a time.

---

# SURFACE LANGUAGE

The interface should feel

Layered

Soft

Refined

Quiet

Surfaces separate information without demanding attention.

---

# COLOR USAGE

Neutral colors dominate.

Brand gold is reserved for moments of importance.

Accent colors communicate meaning—not decoration.

---

# SHADOWS

Soft.

Diffuse.

Natural.

Never dramatic.

Shadows create hierarchy,

not spectacle.

---

# GLASS

Used sparingly.

Reserved for overlays,

dialogs,

floating toolbars,

command palette,

and AI assistant.

Never turn the application into a glassmorphism showcase.

---

# GRADIENTS

Minimal.

Large.

Subtle.

Low contrast.

Never use vibrant rainbow gradients.

---

# TEXTURES

Very subtle paper-inspired textures may appear in marketing pages.

Application screens remain mostly clean.

Noise should never distract from text.

---

# ICONS

Support understanding.

Never become decoration.

Typography carries the interface.

---

# MOTION

Motion should feel invisible.

Users should notice responsiveness,

not animation.

---

# READING EXPERIENCE

Reading comfort is the highest priority.

Everything should improve readability.

Nothing should reduce concentration.

---

# CONSISTENCY

Users should recognize BookLoom from a single screenshot.

Every screen should feel like part of one product.

---

# FINAL RULE

If a design choice makes BookLoom look like a generic AI startup,

reject it.

If it makes BookLoom feel like a premium publishing platform,

accept it.
