# BOOKLOOM BACKGROUND SYSTEM

Version: 1.0

Status: Approved

Priority: CRITICAL

---

# PURPOSE

Backgrounds create atmosphere.

They establish hierarchy.

They separate workspaces.

They should never compete with content.

Users should rarely notice the background consciously.

They should simply feel comfortable spending hours writing.

---

# DESIGN PHILOSOPHY

Backgrounds should feel like

Premium paper

Luxury publishing

Modern architecture

Quiet museums

Natural light

Never

Gaming UI

Neon

Cyberpunk

Glass overload

Dark gradients everywhere

---

# BACKGROUND HIERARCHY

Level 1

Canvas

↓

Level 2

Section

↓

Level 3

Surface

↓

Level 4

Overlay

↓

Level 5

Floating Elements

Each level should remain visually distinct.

---

# PRIMARY APPLICATION BACKGROUND

Color

Warm Off White

Very subtle paper tone

No visible gradients

No illustrations

No patterns

No decorative shapes

Purpose

Reduce eye fatigue during long writing sessions.

---

# LANDING PAGE BACKGROUND

Canvas

Warm Ivory

↓

Very subtle radial light

↓

Paper grain

↓

Extremely soft editorial texture

The landing page may feel richer than the application.

---

# DASHBOARD BACKGROUND

Clean neutral surface.

Very light elevation differences.

No hero gradients.

No floating decorative objects.

Dashboard content should always dominate.

---

# EDITOR BACKGROUND

Pure reading environment.

Solid neutral color.

Maximum contrast for typography.

No textures behind the writing canvas.

No animated backgrounds.

No decorative elements.

The editor exists only for writing.

---

# AUTHENTICATION BACKGROUND

Simple.

Calm.

Centered.

Large empty space.

Optional soft radial light behind authentication card.

Nothing else.

---

# AI WORKSPACE

Same foundation as dashboard.

Never create a separate futuristic AI theme.

AI is a feature,

not another product.

---

# SETTINGS

Flat background.

Minimal contrast.

No decorative artwork.

---

# BILLING

Flat neutral background.

Cards provide hierarchy.

No gradients.

---

# MODALS

Use backdrop.

Background blur only.

Do not introduce new colors.

---

# DRAWERS

Same surface family as sidebar.

Never darker than dialogs.

---

# SIDEBAR

Slightly elevated surface.

Clearly separated from page canvas.

Never use strong shadows.

---

# TOP NAVIGATION

Either

Transparent over page

or

Same surface as sidebar.

No heavy borders.

---

# SECTION BACKGROUNDS

Use surface color differences.

Avoid colored sections.

Hierarchy comes from spacing first.

---

# PAPER TEXTURE

Allowed only

Landing

Marketing

Book showcase

Never inside editor.

Opacity

Less than 3%.

---

# NOISE

Very subtle.

Large scale.

No visible grain.

Never distract from typography.

---

# GRID OVERLAY

Not used by default.

Allowed only

Developer documentation

Design documentation

Never product UI.

---

# DECORATIVE SHAPES

Avoid.

If used,

they must remain outside reading areas.

Never overlap text.

---

# GRADIENTS

Large.

Soft.

Very low contrast.

One gradient per screen maximum.

Never stack gradients.

---

# RADIAL LIGHT

Allowed

Hero sections

Authentication

Marketing

Never dashboard.

Never editor.

---

# IMAGES

Background images are prohibited inside the application.

Use illustrations only when they communicate information.

---

# CONTRAST

Background should always make text easier to read.

Never sacrifice readability for aesthetics.

---

# DARK MODE

Dark charcoal surfaces.

Never pure black.

Subtle elevation differences.

Maintain comfortable reading contrast.

Avoid glowing backgrounds.

---

# HIGH CONTRAST

Flat backgrounds.

Maximum readability.

No textures.

No gradients.

---

# PERFORMANCE

Backgrounds should use

CSS colors

CSS gradients

Tiny procedural textures

Avoid large background images.

---

# ACCESSIBILITY

Respect

prefers-contrast

Maintain WCAG AA contrast.

Never encode information using background color alone.

---

# REVIEW CHECKLIST

✓ Background supports content

✓ No unnecessary decoration

✓ Typography remains dominant

✓ Consistent across screens

✓ Accessible

✓ Optimized

✓ Matches premium editorial identity

---

# FINAL RULE

A BookLoom background should disappear behind the user's work.

If users remember the background more than their writing,

the background is too loud.
